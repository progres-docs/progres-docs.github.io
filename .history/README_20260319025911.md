# PROGRES Docs 📚

**Documentation communautaire ouverte pour la plateforme PROGRES des universités algériennes.**

🌐 **Site en ligne :** [https://progres-docs.github.io](https://progres-docs.github.io)

---

## C'est quoi PROGRES Docs ?

PROGRES est le système de gestion intégré de l'enseignement supérieur algérien (MESRS). Il est utilisé quotidiennement par des milliers de personnels universitaires à travers l'Algérie — mais il n'existe aucune documentation publique officielle.

**PROGRES Docs** est une initiative communautaire qui vise à combler ce vide : une documentation libre, ouverte aux contributions, rédigée par et pour les utilisateurs de la plateforme.

## Comment contribuer ?

Toute personne travaillant avec PROGRES peut contribuer, qu'elle soit technicienne ou non.

### Je suis à l'aise avec GitHub

1. Forkez ce dépôt
2. Créez une branche : `git checkout -b feat/nom-de-votre-contribution`
3. Faites vos modifications dans le dossier `docs/`
4. Soumettez une Pull Request

Consultez le [guide de contribution](./CONTRIBUTING.md) pour les détails.

### Je ne suis pas technique

Pas de problème — vous pouvez contribuer sans toucher au code :

- 🐛 [Signaler une erreur ou une imprécision](https://github.com/progres-docs/progres-docs.github.io/issues/new?template=erreur.md)
- 💡 [Proposer du contenu manquant](https://github.com/progres-docs/progres-docs.github.io/issues/new?template=contenu.md)
- 📸 Partagez des captures d'écran et descriptions par email _(adresse à venir)_
